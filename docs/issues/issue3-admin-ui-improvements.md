# [enhancement] 管理画面（admin.html）のUI/UX改善

## 概要
管理画面のデータ一覧タブを中心としたUI改善

---

## 改善項目

### 1. サイドバー
- [ ] サイドバーをクリックで開閉できるようにする
- [ ] 使用しない時は自動でクローズ（アイコン程度に）

### 2. フィルターエリア
- [ ] 「状態」フィルターを削除 → 「保守会社」フィルターに変更
- [ ] 保守会社フィルターは横幅詰めの枠に

### 3. ボタン追加
- [ ] 「点検レポート出力」ボタンを追加（赤いボタン）
  - 出力イメージ: タイトル、印刷日時、選択中の点検リスト
  - Excelファイル形式

### 4. テーブル列の変更

#### 現状の列順:
チェック, 登録者, 物件, 点検種別, 開始日, 状態, 登録日時, 操作

#### 改善後の列順:
チェック, 物件コード, 物件名, 点検種別, 点検開始日, 点検終了日, 掲示備考, 保守会社, 登録日時, 登録者, 操作

#### 詳細:
- [ ] 物件列を「物件コード」と「物件名」に分割
- [ ] 「状態」列を削除（承認済のみCSV出力するので不要）
- [ ] 「保守会社」列を追加
- [ ] 「点検終了日」列を追加
- [ ] 「掲示備考」列を追加
- [ ] 「登録者」列を登録日時の右側へ移動（名前が長くなる可能性）

### 5. チェックボックス
- [ ] デフォルトで全て選択状態にする

### 6. 並び替え機能
- [ ] 各列ヘッダーに並び替えボタン（▲▼）を追加

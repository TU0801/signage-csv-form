## 1. 必須項目のバリデーションエラー（動画07）

### 問題の概要
フォームに全項目を入力しても「必須項目を入力してください」というエラーが表示され、データを追加できない。

### 再現手順
1. 点検CSV作成フォームを開く
2. 管理者ログインで保守会社「日本オーチス・エレベータ 株式会社」を選択
3. 物件コード「120109 アソシアグロッツォタイムズスイート博多」を選択
4. 端末ID「z1002A01」を選択
5. 点検工事案内「エレベーター定期点検」を選択
6. 貼紙「テンプレート」を選択
7. 点検期間（開始日・終了日）を入力
8. 掲示備考「aaa」を入力
9. 「データを追加」ボタンをクリック
10. **→ 「必須項目を入力してください」エラーが表示される**

### 期待される動作
全項目入力済みの状態でデータが正常に追加されること

### 優先度
🔴 **高** - 基本機能が使用不可

## 2. 管理者ログイン時の物件コードフィルター不具合（動画08）

### 問題の概要
管理者ログインで保守会社を選択した際、物件コードのドロップダウンがその保守会社の物件だけにフィルターされていない。

### 再現手順
1. 管理者ログインで保守会社「株式会社 えん建物管理」を選択
2. 物件コードのドロップダウンを開く
3. **→ 全物件（120109〜120421）が表示される**

### 期待される動作
選択した保守会社に紐づく物件のみがドロップダウンに表示されること

### 優先度
🟡 **中** - 運用には支障ないが、効率が低下

## 3. テンプレート以外の追加時に文字合成が不要（動画09）

### 問題の概要
貼紙で「追加」モード（カスタム画像アップロード）を選択した際、プレビューに文字合成が適用されてしまう。テンプレート以外の画像を使用する場合、文字合成は不要。

### 再現手順
1. 貼紙で「追加」を選択
2. カスタム画像をアップロード
3. 掲示備考にテキストを入力
4. **→ プレビューで画像上に文字が合成されて表示される**

### 期待される動作
- 「テンプレート」選択時のみ文字合成を適用
- 「追加」（カスタム画像）選択時は文字合成なしでそのまま表示

### 改善提案
- 「追加」モード時は文字合成設定エリアを非表示にする
- または、文字合成ON/OFFのトグルを追加する

### 優先度
🟡 **中** - UX改善

## 4. マスター管理の点検種別に関する2つの問題（動画10）

### 4-1. 点検種別「未分類」を設定しようとすると保存できない

#### 問題の概要
点検種別を編集する際、カテゴリで「カテゴリを選択」（未分類/空白）状態で保存しようとすると保存に失敗する。

#### 再現手順
1. マスター管理 → 点検種別タブを開く
2. 「自転車撤去」などの項目を編集
3. カテゴリを「カテゴリを選択」（未選択状態）にする
4. 保存ボタンをクリック
5. **→ 保存に失敗する（現在カテゴリは「-」として表示されている項目がある）**

#### 期待される動作
- カテゴリ未設定（未分類）状態での保存を許可する
- または、「未分類」を選択可能なカテゴリとして追加する

#### 優先度
🟡 **中** - データ整合性に影響

---

### 4-2. 点検種別の並び順を変更したい

#### 要望の概要
マスター管理の点検種別一覧で、項目の並び順をドラッグ&ドロップなどで変更したい。

#### 現状
現在の点検種別一覧の表示順序:
- 自動扉点検（点検）
- 裏口自動ドア工事（工事）
- 駐輪場自動ドア工事（工事）
- エントランス自動ドア工事（工事）
- 自転車撤去（-）
- 建築設備調査（点検）
- ...

#### 改善提案
- ドラッグ&ドロップで並び替え機能を追加
- または、ソート順を指定できるフィールドを追加

#### 優先度
🟢 **低** - 利便性向上

## 技術的補足

### 動画07の問題について
画面上で確認できる限り、以下の項目は全て入力済み:
- 物件コード ✓
- 端末ID ✓
- 点検工事案内 ✓
- 貼紙（テンプレート）✓
- 点検期間 ✓
- 掲示備考 ✓

**推測される原因**:
- 画面外の隠れた必須項目の存在
- フロントエンドのバリデーションロジックのバグ
- 特定の保守会社・物件の組み合わせで発生する問題

### 動画08の問題について
APIレベルで保守会社IDによる物件フィルタリングが実装されていない、または管理者権限では意図的にフィルターが無効化されている可能性があります。仕様確認が必要です。

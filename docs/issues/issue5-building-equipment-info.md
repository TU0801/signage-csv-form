# [enhancement] 建物毎の基本設備情報管理機能

## 概要
紐付け管理画面に、建物毎の設備情報を入力・管理する機能を追加

---

## 背景
- 現状: 保守会社と建物の紐づけのみ
- 要望: 建物毎に設備情報（エレベーター、宅配ボックス、自動扉など）を登録したい

---

## 機能要件

### 設備情報の項目
各建物に対して、以下の設備情報を複数登録可能:

| 項目 | 説明 |
|------|------|
| 設備種類 | エレベーター、宅配ボックス、自動扉など（点検カテゴリのみ） |
| 保守会社 | 設備毎の担当保守会社 |
| 点検月 | 定期点検の月 |
| 備考 | 自由入力 |
| 備考2 | 自由入力 |

### 登録イメージ
```
建物: アソシアグロッツォ天神サウス (120406)
├─ エレベーター | 日本オーチス | 1月,7月 | 2基 | -
├─ 宅配ボックス | ○○会社 | 6月 | 1F | -
└─ 自動扉 | △△会社 | 3月,9月 | エントランス | -
```

### UI
- 各物件行に「設備情報編集」ボタンを追加
- クリックでモーダル or 展開して設備一覧を表示・編集

# [bug] 追加画像モードでTPLNoにファイル名が入らない

## 概要
追加画像（カスタム画像）モードでデータ登録した場合、CSV出力時の点検案内TPLNo列が空になる

## 再現手順
1. 一件入力画面で「追加」モードを選択
2. カスタム画像をアップロード
3. データを追加・申請
4. 管理画面からCSVエクスポート

## 現状
- TPLNo列が空白

## 期待動作
- アップロードしたファイル名がTPLNo列に入る

## 対象ファイル
- js/script.js
- js/admin.js (CSV出力部分)

## 備考
テンプレートモードでは正常動作
